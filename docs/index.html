Questions

Is it safe to freeze updates for years?

It also pauses security patches, so freeze for as long as you can accept that risk. Many people use it on offline machines, lab PCs, or to dodge a bad update, then resume every few months to catch up.

Will Windows SmartScreen warn me?

Possibly. New open-source tools often show a "not commonly downloaded" notice until they build reputation. Compare the SHA256 in each release with your download, or build it from source.

How do I undo it?

Click Resume in Stasis, or restore any earlier backup. Both are one click.

Does it break Windows Update?

No. It doesn't disable services or edit system files. It sets the pause dates that Windows Settings already understands.

Why admin rights?

The pause values live in HKEY_LOCAL_MACHINE, which only administrators can write.
