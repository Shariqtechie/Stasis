# VM test sheet

For each Windows 11 edition and version, run these steps and note the result.

1. Open Stasis. Is the OS line correct? Does the window look right (Mica, no scrollbar)?
2. Freeze for **3 years**. Open Settings → Windows Update. Does it show paused until the right date? Test this on a PC that has never been paused from Settings.
3. Reboot. Is the pause still shown in Stasis and in Settings?
4. Freeze with a **custom date** (for example 2035). Does Settings accept it?
5. Click **Resume updates**. Does Settings show updates active?
6. Click **Restore** on a backup. Do the values come back?
